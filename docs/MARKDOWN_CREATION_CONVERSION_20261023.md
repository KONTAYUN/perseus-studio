# Markdown 新建与 TXT 转换验收（2026-10-23）

## 交付行为

- 工作区新建文件及文件夹内新建文件默认使用 `新建文稿.md`，同名文件自动编号。
- TXT 编辑器右上角显示单个“转换为 Markdown”图标；转换成功后，同一位置显示 Markdown 的富文本/纯文本切换图标。
- 转换保留目录、文件主体名称和正文，不调用模型、不改写正文、不提供反向转换按钮。
- 转换前保存当前草稿，使用保存后的内容哈希进行服务端条件重命名；源内容变化、保存失败或目标已存在时停止并提示。
- 转换期间阻止重复提交、旧路径自动保存、关闭或拖出标签；切换文件等待转换完成。

## 检查中修复的问题

文件名编号原先只检查可见文件树行，收起的文件夹中已有同名文件时，新建会失败。现在检查完整子树，并增加回归。

重命名接口增加可选 `expected_hash`，保持旧调用兼容。目标重名使用结构化 `ErrPathExists` 返回 409，内容过期返回 409，避免根据错误文案猜测原因。
