## 修复内容

| 编号 | 问题 | 修复及验证边界 |
| --- | --- | --- |
| FA-01 | 上传附件只有当轮 HTTP 请求携带正文，后续轮次丢失 | 新增私有 `message_attachment_payloads` 表，与用户消息、运行受理在同一事务提交；读取历史时恢复上传的文本和受支持图片；分支复制、重新生成、后台任务均复用持久上下文。公开消息 JSON 只返回附件元数据。附件内容计入上下文预算并进入摘要输入，现有长度限制保留。后台任务截取来源用户消息之前的历史，不读取后来的前台消息或摘要。 |
| FA-02 | 后台任务创建成功、转交事件失败，显式继续后重复创建 | 后台任务、助手回执、转交事件、前台成功终态及检查点清理改为同一 SQLite 事务。事务提交前 worker 看不到任务。重试已提交转交复用任务及回执；能够匹配旧版同 source_run_id 的任务，不删除旧数据。三个事件提交点分别注入失败，验证零残留，失败→显式继续→重试只产生一个任务和回执。 |
| FA-03 | AI 层与 API 层重复发出 run_failed | AI 层改为非终态 `agent_execution_failed`，API/store 统一提交运行失败状态和终态事件。重复失败回调不重复提交，成功后迟到失败不改写状态；显式继续后允许新尝试产生自己的终态。故障注入验证状态和事件共同回滚，真实 HTTP 模拟 401／空回复验证各只有一个 run_failed。 |
| FA-04 | 聊天任务卡永久显示创建时 pending | 卡片读取现有任务轮询数据；超出最近任务列表时按任务 ID 获取状态，活动任务继续轮询；已删除／不可访问时明确提示，获取失败不展示旧 pending。新的转交正文不再写入静态状态。浏览器验证不开任务面板也能更新、删除后不残留 pending。 |
| FA-05 | 裸 URL 吞并后续中文标点和正文 | 在 GFM 语法树中只修正自动识别的裸链接边界，正文保留；显式 Markdown 链接、尖括号链接、行内代码与百分号编码 URL 不变。单测及实际聊天渲染验证。 |
| FA-06 | 二进制可上传但不能下载，ZIP 静默跳过 | 增加受身份和工作区路径限制的原始字节下载接口，支持 Range、附件文件名、nosniff；前端通过 Blob 下载，ZIP 使用 Uint8Array，不经过 JSON 文本转换；所有文件显示下载按钮。中文文件名、0xff／0x00／CRLF 单文件和混合文件夹 ZIP 逐字节核对；批量 ZIP 超过 256 MiB 或 65535 个文件明确拒绝，防止浏览器无界缓冲。 |
| FA-07 | 越权删除会话返回 200、取消任务返回 500 | 不属于当前用户和不存在的对象统一返回 404；保留已有用户隔离。回归确认所有者会话、任务状态和取消标记不变。 |

## 复验中新发现的 Windows 文件共享冲突

首次完整浏览器回归为 38 通过、1 失败、1 opt-in 跳过。失败发生在自动保存冲突处理后的读取请求：Windows 返回 sharing violation，API 返回 500。原始日志及 trace 保留在 `browser-all.log`、`windows-sharing-failure/`。

修复：有界文件读取只针对 Windows 数值错误码 32／33（共享／锁冲突）短暂重试，最多六次、累计退避 150 ms；其他平台和权限、缺失、大小超限等错误不重试。持续占用仍返回原始错误，不吞错、不覆写文件。新增两个 Windows 专项回归，用系统独占文件句柄实际复现短暂占用、持续占用和非目标错误；连续三轮通过。

## 拖拽收尾

重复使用的浏览器测试目录积累了较长文件树，原生拖拽脚本出现拖错源项／未触发 drop 的不稳定现象；网络 trace 明确记录了与测试期望不同的源路径。测试增加滚动居中、源位置命中核对、目标可见性和实际排序请求 source 断言，保留未通过日志，不将误拖归为模型问题。

同时检查到产品 `onDrop` 依赖 React 异步悬停状态：最终 dragover 未提交时可能忽略排序。已改为从 drop 事件的位置、DataTransfer 源路径及当前兄弟节点计算目标，悬停状态仅用于视觉提示。新增浏览器回归故意不给悬停状态，验证排序请求和刷新后的顺序；连续三轮通过。真实原生拖拽仍在重复使用的长列表测试目录中存在自动化不稳定，不能把该环境的重复运行宣称为全通过。
