# Agent Mature-Reference Matrix

Primary reference baseline: OpenAI Codex open-source commit `d72d669`.
Additional compatibility reference: Roo Code style configurable providers.
Explicit agent termination reference: Roo Code commit
`b867ec9145750d0ae1ff7f02d35406e9bf2a0b16`.

This matrix is the required record for any mature-agent behavior adopted by
Perseus Agent Kernel. A behavior is not considered implemented unless it has a
reference, a Perseus implementation entry, and at least one regression test or
explicit follow-up gap. This does not mean Perseus runs Codex internally; the
production kernel is a lightweight Perseus-native loop.
