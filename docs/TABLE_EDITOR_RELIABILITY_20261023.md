# 表格编辑稳定性修复与验收（2026-10-23）

## 已确认的原因

1. 表格单元格内按回车后，Markdown 序列化器生成 `<br>`。文档编辑资格检查却把该标记视为不支持的 HTML，导致正在编辑的文档立即切换到只读预览。
2. 换行依赖 Markdown 库的通用 HTML 回退，没有显式的 Markdown 换行节点契约；在无浏览器 DOM 的解析环境中会成为字面文字。共享预览也直接显示该标记。
3. 行列操作藏在段落菜单底部，只能向下加行、向右加列，缺少删除行列和明确的表格退出入口。
4. 删除原表头，或粘贴表格软件的 HTML 单元格时，首行可能成为普通单元格。序列化器随后自动补空表头，造成刷新前后行数变化。

## 修复

- 共用属性为空的 `<br>`、`<br/>`、`<br />` 语法识别规则，明确解析为 `hardBreak`。格式资格检查、富文本解析和安全预览保持一致；代码示例、转义文本和带属性的未知 HTML 不会被当成可执行 HTML。
- 表格内 Enter 使用换行节点；支持 Shift+Enter、原有 Tab/Shift+Tab 导航和末格 Tab 新增行；Ctrl/⌘+Enter 在表格后创建正文。
- 选中表格时直接显示尺寸、行/列菜单、“继续写”和删除表格。支持前后增删行列，保留至少一行一列；删除整个表格支持撤销。
- 六点菜单按表格上下文展示操作，支持在表格前后插入正文；不提供嵌套表格、代码块等无法稳定映射到 GFM 单元格的块操作。
- 通过 ProseMirror 事务插件维护“一行表头，其余为正文单元格”的结构约束，覆盖菜单、粘贴和撤销路径；保留单元格内容及属性。
- 仍不支持的扩展文档保留原文预览，提示区直接提供“切换纯文本继续编辑”，避免只读状态没有明确操作入口。
