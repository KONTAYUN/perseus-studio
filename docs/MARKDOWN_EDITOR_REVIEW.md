## 交付功能

- AI 消息使用 React Markdown / GFM 渲染标题、强调、列表、引用、表格、行内代码和代码块；流式的非空正文沿用同一渲染入口。用户消息和错误保留字面文本。
- 代码块显示语言与复制按钮，保留命令缩进、空行，反馈复制成功/失败。复制不会执行命令，整条消息原有复制功能保留。
- `.md`、`.markdown`、`.mdown` 默认显示可编辑文档，右上角下载旁切换富文本/纯文本。每个编辑面板按文件保存当前显示模式，切换布局不会重置。
- 选中文字出现浮动工具条：粗体、斜体、删除线、行内代码、编辑/移除链接、清除文字格式。
- 当前段落左侧六点按钮打开菜单：正文、一至三级标题、无序/有序/任务列表、引用、代码块、分隔线、表格、下方插入段落、删除段落。表格内支持增加行/列、删除表格。
- 富文本由 Tiptap / ProseMirror 管理选区和撤销。保存依然只有 Markdown，接入原自动保存、哈希冲突检查和 Ctrl/Cmd+S 手动保存，不另建文档数据库。

## 视觉复核

| Before | After | Why |
| --- | --- | --- |
| AI 消息直接呈现文字，命令难以单独取用 | 共享 Markdown 排版，代码块带语言标签与复制反馈 | 提高阅读和操作效率，保留代码空白 |
| Markdown 文件只有源码编辑 | 默认文档视图，下载旁保留源码入口 | 阅读与格式调整不要求手写标记 |
| 无选区/段落操作入口 | 浮动文字工具条、左侧六点段落菜单 | 常用操作在上下文附近完成，避免常驻大工具栏 |
| 新增任务项的复选框和文字曾分成两行 | 按实际 NodeView DOM 修正为同一行 | 交互测试之外再用截图检查实际排版 |
| 布局切换会卸载面板局部状态 | 显示模式归编辑标签状态管理 | 防止返回编辑器后突然切换视图 |

浅色、真实主题按钮切换后的深色、760px 窗口及段落菜单均进行了浏览器截图复核。浮层限制在视口内，代码与表格可独立横向滚动。六点按钮提供点击菜单，本轮未提供拖动块排序。

## 数据与安全边界

- 打开文档、切换显示模式不序列化写盘；用户实际编辑后会规范化部分 Markdown 的表示方式，例如列表标记和表格间距。保留原有 LF/CRLF 与末尾换行习惯。
- 外部文件版本替换时重新建立编辑器，清空旧撤销历史，防止重新加载冲突文件后 Ctrl+Z 恢复过期内容。外部保存冲突仍保留本地和磁盘两侧，不能静默覆盖。
- Frontmatter、原始 HTML、脚注定义、数学扩展、指令块、Wiki 链接、引用式链接定义使用只读预览并保留源码编辑；超过 512K UTF-16 code units 的文档也使用该回退。保护检测允许围栏/缩进代码和行内代码中的 HTML 示例，以及普通自动链接。此检测是保守兼容策略，不是所有 Markdown 方言的无损编辑保证。
- 不启用原始 HTML 渲染，不使用自建 `contenteditable` / `execCommand` 编辑器。链接拒绝执行协议、控制字符、反斜杠和协议相对地址。
- 复制依赖浏览器 Clipboard API 的安全上下文与权限；不支持时明确提示手动选择复制。Windows 系统剪贴板可能把 LF 规范化为 CRLF，测试只对读回行尾进行归一化。
- 普通 Markdown 格式可编辑；颜色、下划线等非通用 Markdown 样式、数学公式/图表专用渲染未实现。工作区相对图片尚未通过带鉴权的文件 API 解析，外部图片可显示；相对文档链接未接入编辑器内部文件跳转。

## 代码边界

- `components/markdown`：共享安全渲染、代码块复制、显示/编辑兼容策略。
- `components/editor/MarkdownDocument`：富文本惰性加载、扩展语法回退、外部版本替换。
- `components/editor/richText`：编辑器扩展、代码节点视图、选区工具条、段落菜单。
- `hooks/useRichTextControls`：选区/滚动定位与监听器清理；原编辑器 hook 持有文件、显示模式及保存状态。
- `styles/markdown.css` 与 `styles/rich-editor.css`：作用域内排版和控件；沿用共享 Button、Input、IconButton、SegmentedControl、AnchoredPopover。

已同步结构标准、架构说明、健康验收项与 UI 设计系统，普通生产文件保持行数门禁。
