# 文稿编辑闭环实施记录

## 授权范围与原则

实施用户批准的完整文稿编辑闭环计划。Markdown 是唯一正文，保留 Tiptap/ProseMirror，使用 remark/mdast 适配，后端 Goldmark 验证。先保证编辑操作与提交正确，再提供恢复；不以恢复代替正确性。

阶段：格式契约与语料 → 事务/局部保存 → 通用格式交互 → Agent 隔离修复 → 长文与版本 → 全量验收。实际结果追加到本文，不将计划当作已经完成。

## 架构决定

- 语法树、原文来源映射和修订号由 document adapter/session 所有；React 视图负责交互。未改根结构保留原文，未知载荷不执行。
- 编辑器支持节点与 Markdown 输出在候选重解析后进行规范化比较；失败保留草稿，不通过关键词猜测来重写。
- `.md/.markdown/.mdown` 共用格式契约。源码入口仅在替代能力与回归完成后移除。
- 写入性测试隔离数据库/用户目录。8080 仅在任务空闲、备份和验收后更新。
- 不创建子 Agent、不推送、不部署云端、不删除用户数据、不输出凭证。

## 界面评审

| Before | After | Why |
| --- | --- | --- |
| 标记匹配触发疑似错误 | 依据结构和候选转换区分兼容、保留、格式异常、编辑器故障 | 合法文字不应触发修复 |
| 特殊语法要求用户编辑原始标记 | 局部保留与助手处理入口 | 普通用户不需要理解源码 |
| 长文或组件故障退回源码 | 分段富文本与明确的加载恢复反馈 | 不把技术故障包装成文档错误 |

## 验证记录

本轮验收进行中。以下均为实际执行记录，前轮通过不能替代最终构建的重新验收。

### 已实现的边界

- remark/mdast 与 Tiptap schema 映射、根结构原文范围及 UTF-16 位置、BOM/CRLF 保留、候选重解析和结构比较。移除 `@tiptap/markdown` Beta 依赖及旧分段转换器，回归统一使用生产适配器。
- 原文为唯一正文；编辑修订在 Worker 中处理。根结构分页维持全文引用作用域及统一撤销。组合输入期间不转换或提交；过期会话响应不能覆盖新视图。
- 表格行列、对齐、单元格换行、导航和退出；图片、脚注、公式、提示块、头信息表单。头信息仅替换被编辑的标量范围，保留未编辑注释与键名；复杂属性完整保留。
- 特殊内容局部惰性保留，不执行原始 HTML。常规 Markdown 没有源码切换入口；TXT 与单向转换仍保留。脚注弹层保留段落与文字格式。
- 浏览器草稿与历史归档、Worker 故障重试、版本预览/CAS 恢复、文件身份随移动和回收站跟随。修复/分块提交写前记录意图，数据库提交结果不确定时按精确内容哈希对账，不重放到新版本。
- 普通 Markdown 写入先验证；多文件补丁先验证全部候选。Markdown 分块暂存并使用逐块回执，正式文件仅在最终提交时更新。
- 修复授权随队列、消息、运行和检查点持久化；仅允许目标读取、目标候选补丁、结束或询问四种能力。候选最多两次，失败也计数。暂存事件不能计作已应用变更或触发文件刷新。
- 版本/候选应用检查目标、当前草稿、结构和磁盘哈希；应用后后台刷新不能重建仍有本地编辑的组件。

### 本轮发现并补充修复

1. 快速切换布局早于结构化事务保存：布局变更前共同 flush；关闭编辑面板同样使用保存边界。
2. 表格多行纯文本粘贴在重开后丢换行：单元格内软换行显式映射 hardBreak；单个空单元格换行不能被当作空段落忽略。
3. 撤销后紧接重做失效：Tiptap `setEditable` 默认触发 update，且禁用期间会失去焦点。状态切换不再伪造编辑事件，结束后恢复原焦点。
4. 旧会话异步响应和恢复操作覆盖新视图：会话身份检查、局部客户端捕获及视图操作边界；Worker 终止后重试从保留来源和待处理事务恢复。
5. 链接定义删除导致其他位置引用不能保存：依赖范围扩展至受影响引用；只将这些引用改为携带相同地址、标题的普通链接/图片。
6. 编辑公式时丢弃原始 math 元信息：schema、适配和语义比较共同保留 meta。
7. AVIF 前端允许但 Go MIME 检测不识别：仅检查有界 ISO-BMFF ftyp 品牌，拒绝截断/溢出头与 SVG。
8. 待修复请求替换普通挂起消息：前后端共同拒绝替换，修复不能作为 steer 投递。
9. 跨面板搬移及再次激活当前文件可能读取 flush 前快照：统一先 flush 后取当前快照；修复准备也必须等待待处理事务。
