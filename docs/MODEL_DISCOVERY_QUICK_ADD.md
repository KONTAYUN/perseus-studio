# 模型列表快捷添加

验证日期：2026-10-22。

| Before | After | Why |
| --- | --- | --- |
| 获取列表后只能填写单个模型，保存后需要重复操作 | 每行增加加号，直接创建配置，保留列表和连接参数 | 一次获取即可连续添加多个模型 |
| 编辑已有配置时，浏览器没有保存的 Key | 后端经管理员鉴权后复用指定配置的凭据 | 不要求再次输入 Key，也不向浏览器返回凭据 |
| 连点可能重复提交，失败反馈不清楚 | 保存期间锁定提交；成功显示勾号，失败提示并允许重试 | 让添加状态明确，避免快速连点重复创建 |
| 切换连接后可能显示上一请求结果 | 连接变更中止请求并丢弃过期响应 | 列表和当前连接保持一致 |

点击模型名称仍可填入手动配置表单。加号始终创建新配置，不覆盖正在编辑的配置；已有默认模型保持不变。现有相同协议、地址、模型 ID 的配置显示为已添加。无配置时首个模型的默认行为沿用后端原有规则。

实现按界面、异步 hook、输入构造 helper 和后端凭据复用划分，没有数据库迁移。加号支持键盘、提示文本、忙碌状态及深浅色外观。
